How it works

Four stages. One verdict.

Guardian intercepts every window.solana.signTransaction call before the wallet popup appears.

01 В· INTERCEPT
Browser extension
A Manifest V3 extension monkey-patches the wallet provider and pauses the request before the user sees a popup.
02 В· DECODE
Go backend
Decodes IDL instructions, simulates the transaction against a fork, and checks 14 heuristics вЂ” drain, delegate, authority change, blocked domain.
03 В· SCORE
AI co-signer
A local Python service produces a 0вЂ“100 risk score and a one-sentence English explanation вЂ” no opaque vendor calls.
04 В· ENFORCE
On-chain policy
High-risk transactions trigger an Anchor program's co-sign requirement вЂ” enforcement lives on Solana, not in the extension.
Architecture

Built on what Solana already gives you.

No custodial steps. No proxy RPC. The user's wallet still signs вЂ” Guardian just makes sure they know what they're signing.

Anchor program (on-chain)
Stores wallet policies and review records. submit_review + cosign instructions.
Go API (off-chain)
Orchestrates decode + simulate + AI score. Stateless, horizontally scalable, p95 < 200 ms.
Python AI service
FastAPI + scikit-learn classifier trained on 40k labelled drain / phish / safe transactions.
Browser extension
React + TypeScript. Wraps Phantom, Backpack, and Solflare with no UX changes for safe transactions.
